# v0.6.0: small tools and browser library removal

**The browser library is removed. An import not run before upgrading cannot be run afterward. Everyone at the table must complete their browser library import before upgrading to v0.6.0.**

Run the import in v0.5.0, in each browser and at each original server address that holds a library you want to keep. Open a room you run, then choose **Import browser library** in the Asset Manager. Any account can create a room to do this. Resolve skipped images or quota failures before upgrading; see the [v0.5.0 import instructions](v0.5.0.md#bring-over-each-browser-library).

Opening v0.6.0 permanently deletes the browser's old maps, tokens, groups, states and image storage. The Asset Manager no longer offers the import. The browser keeps its player id, nickname and settings, so item ownership and trusted-player recognition survive. New browsers store only identity there; built-in images come from the server set. Rooms, scenes, placed images, room libraries and account libraries on the server are unchanged by this removal.

## Small tools

- The Text tool (`x`) places plain text on the Text layer. Edit its text, colour and one of four sizes in its menu; colour and size are remembered in each browser. Typing directly on the canvas is not included.
- New notes and text start hidden, visible to their owner and the GM. The GM can show any item, and trusted players can show their own items to everyone; a player who is not trusted sees a disabled Show action and its explanation. Existing items keep their visibility.
- Thin, normal and thick stroke widths apply to new brush strokes, lines and outlined shapes. The choice is remembered in each browser. Filled shapes and fog are unchanged.
- Alt-drag, Duplicate, and copy and paste allocate the next free trailing number in token labels, using the labels the person can see. Labels without a trailing whole number after a space stay as they are.
- For the GM, a click passes through locked items and a double-click selects one. Selection boxes skip locked items; players cannot select them. Holding Space pans during a drawing or fog shape and releasing it continues that shape.

## Upgrade and rollback

Stop the server and back up the complete data directory before replacing the executable; see the [hosting guide](../hosting.md#back-up-and-restore). Complete everyone's browser imports first.

The server database layout stays at 4. A v0.5.0 server can open v0.6.0 rooms. Roll back the interface together with the server, as replacing the single executable does: the v0.5.0 server refuses a player's new hidden note or text from the v0.6.0 interface. Rolling back the executable does not restore a deleted browser library or its import data.

Plain text now renders at its saved line height and takes the width it needs, rather than shrinking to fit a square. Notes still fit their text inside their square. v0.5.0 renders unsquared text differently, so text created in v0.6.0 can look different after rollback.
